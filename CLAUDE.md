# CLAUDE.md

Les `AGENTS.md` først. Den gjelder for alle AI-agenter i dette repoet, også Claude Code.

Kort oppsummert:
- Les `memory.md`, `todo.md` og siste del av `log.md` før du starter.
- Logg alt du gjør i `log.md` med tidsstempel (Europe/Oslo).
- Ingen emoji og ingen tankestrek (em dash) i dokumentasjon. Dokumentasjon på norsk, tekst i spillet på engelsk.
- Arkitektur og oppskrifter for nytt innhold: `docs/ARCHITECTURE.md`.
- Design: `docs/GDD.md`. Grafikkbestillinger: `docs/ART_PROMPTS.md`.
- Kjør `npm run typecheck` og gjerne `npm run build` før du sier deg ferdig.
